# AI面试帮手-面试克星 Spec

## 1. 项目信息
- 项目背景：专注于面试场景的 AI 应用，旨在通过 AI 评估功能以及模拟面试功能帮助求职者准备面试
- 技术栈：
前端Vite + React 19+ TypeScript+Tailwind+shadcn/ui
状态管理 Zustand
路由 React Router v6
后端Node.js + Express + TypeScript
数据库MongoDB
部署 Vercel
- 截止时间：2026年9月1日(最晚)
